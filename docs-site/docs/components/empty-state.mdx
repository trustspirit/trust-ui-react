# EmptyState

A placeholder for an area that has no data yet — an empty list, a search with no results, a feature that has not been set up.

## Basic Usage

<ComponentPreview code={`<EmptyState
  title="No transactions yet"
  description="Transactions will appear here once you make your first transfer."
/>`}>
  <EmptyState
    title="No transactions yet"
    description="Transactions will appear here once you make your first transfer."
  />
</ComponentPreview>

## Compact

For cards and side panels. Spacing and type are smaller, and actions stack vertically and stretch to the full width.

<ComponentPreview code={`<EmptyState
  compact
  title="No saved recipients"
  description="Save a recipient to send faster next time."
  actions={<Button>Add recipient</Button>}
/>`}>
  <div style={{ width: 280, maxWidth: '100%' }}>
    <EmptyState
      compact
      title="No saved recipients"
      description="Save a recipient to send faster next time."
      actions={<Button>Add recipient</Button>}
    />
  </div>
</ComponentPreview>

## Heading level

`headingLevel` changes the tag (`h1`–`h6`) and nothing else. Choose the level that continues the outline of the surrounding page.

<ComponentPreview code={`<EmptyState headingLevel={2} title="No results for “invoice 2031”" description="Check the spelling or try a different search." />`}>
  <EmptyState headingLevel={2} title="No results for “invoice 2031”" description="Check the spelling or try a different search." />
</ComponentPreview>

## Accessibility

- The title is a real heading (`h3` by default), so screen-reader users can reach the empty area by heading navigation. Set `headingLevel` so levels are not skipped.
- The `icon` wrapper is `aria-hidden` — do not put meaning in it that the title does not also state.
- The root has no role. If the empty state replaces content after a user action (for example a search that returned nothing), announce the result with your own `role="status"` message; do not rely on the heading being noticed.
- `actions` are your own controls and keep their own keyboard behaviour.

| Key | Action |
| --- | --- |
| `Tab` | Moves through the actions |
| `Enter` / `Space` | Activates the focused action |

## Mobile

- Text is capped at about 40 characters per line and centred; it shrinks with the container and long words break, so nothing overflows at 320px.
- Actions wrap in the default layout. Use `compact` in narrow containers to stack them full-width, which gives larger, easier touch targets.
- Use buttons of `size="md"` or larger so targets reach 44px on touch.
