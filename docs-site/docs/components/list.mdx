# List

Rows for settings screens, menus that are pages, and simple collections. It is the narrow-screen counterpart of a table: one item per row, a title, an optional description, and a slot at each end.

## Basic Usage

<ComponentPreview code={`<List aria-label="Settings">
  <List.Item title="Account" description="Profile, password and security" href="/account" />
  <List.Item title="Language" href="/language" trailing="English" />
  <List.Item title="Version" trailing="2.2.0" />
</List>`}>
  <List aria-label="Settings">
    <List.Item title="Account" description="Profile, password and security" href="#account" />
    <List.Item title="Language" href="#language" trailing="English" />
    <List.Item title="Version" trailing="2.2.0" />
  </List>
</ComponentPreview>

A row with `href` is a link and gets a trailing chevron unless you pass `trailing`. A row with `onClick` is a button. A row with neither is plain text.

## Variants

`outlined` draws the list on a sheet surface with a hairline border.

<ComponentPreview code={`<List variant="outlined" aria-label="Settings">
  <List.Item title="Account" href="/account" />
  <List.Item title="Notifications" href="/notifications" trailing={<Badge size="sm">3</Badge>} />
  <List.Item title="Sign out" onClick={signOut} />
</List>`}>
  <List variant="outlined" aria-label="Settings">
    <List.Item title="Account" href="#account" />
    <List.Item title="Notifications" href="#notifications" trailing={<Badge size="sm">3</Badge>} />
    <List.Item title="Sign out" onClick={() => {}} />
  </List>
</ComponentPreview>

## Dividers

`dividers` is on by default. `'inset'` starts the hairline where the text starts, after the leading slot; `false` removes it.

<ComponentPreview code={`<List variant="outlined" dividers="inset" aria-label="People">
  <List.Item title="Kim Seoyeon" description="Finance" leading={<Avatar />} />
  <List.Item title="Lee Dohyun" description="Engineering" leading={<Avatar />} />
</List>`}>
  <List variant="outlined" dividers="inset" aria-label="People">
    <List.Item title="Kim Seoyeon" description="Finance" leading={<span aria-hidden="true">●</span>} />
    <List.Item title="Lee Dohyun" description="Engineering" leading={<span aria-hidden="true">●</span>} />
  </List>
</ComponentPreview>

## Density

By default rows follow the density of the page (`--tui-row-height`). Set `density` to scope it to one list.

  <List.Item title="Compact row" trailing="46px" />
</List>`}>

    <List.Item title="Compact row" trailing="46px" />

## Rows with a control

Put a control such as a Switch in `trailing`. The control is the target; the row itself is not a button.

<ComponentPreview code={`<List variant="outlined" aria-label="Network">
  <List.Item title="Wi-Fi" trailing={<Switch aria-label="Wi-Fi" defaultChecked />} />
  <List.Item
    title="Bluetooth"
    description="Opens the device list"
    href="/bluetooth"
    trailing={<Switch aria-label="Bluetooth" />}
  />
</List>`}>
  <List variant="outlined" aria-label="Network">
    <List.Item title="Wi-Fi" trailing={<Switch aria-label="Wi-Fi" defaultChecked />} />
    <List.Item
      title="Bluetooth"
      description="Opens the device list"
      href="#bluetooth"
      trailing={<Switch aria-label="Bluetooth" />}
    />
  </List>
</ComponentPreview>

### The no-nesting rule

A link or button must not contain another control. When a row has both `href`/`onClick` **and** an interactive `trailing`, List renders two sibling targets inside the list item: the row link or button covers the leading slot and the text, and the trailing control sits next to it, outside the link. A non-interactive `trailing` (a value, a badge) stays inside the link and becomes part of its name.

`trailing` counts as interactive when it is, or wraps, a native control (`button`, `a`, `input`, `select`, `textarea`), a library control (Switch, Checkbox, Button, IconButton, Chip, Select …), or an element with an interactive `role`, a `tabIndex`, or an `onClick` / `onChange` / `href` prop. A custom component that hides its control cannot be detected: pass `trailingInteractive` for it.

## Navigation rows

`selected` marks the current row with `aria-current="true"`. `disabled` rows cannot be activated.

<ComponentPreview code={`<nav aria-label="Main">
  <List dividers={false}>
    <List.Item title="Home" href="/" />
    <List.Item title="Orders" href="/orders" selected />
    <List.Item title="Reports" href="/reports" disabled />
  </List>
</nav>`}>
  <nav aria-label="Main">
    <List dividers={false}>
      <List.Item title="Home" href="#home" />
      <List.Item title="Orders" href="#orders" selected />
      <List.Item title="Reports" href="#reports" disabled />
    </List>
  </nav>
</ComponentPreview>

For a client-side router, pass its link component with `as` and its props with `linkProps`:

```tsx
<List.Item title="Orders" as={Link} linkProps={{ to: '/orders' }} />
```

## Long text

The title is truncated to one line and the description is clamped to two. `multiline` lets both wrap.

<ComponentPreview code={`<List variant="outlined" aria-label="Notices">
  <List.Item
    title="Scheduled maintenance on Saturday between 02:00 and 04:00"
    description="Transfers and card payments are unavailable during the window. Balances are still shown."
  />
  <List.Item
    multiline
    title="Scheduled maintenance on Saturday between 02:00 and 04:00"
    description="Transfers and card payments are unavailable during the window. Balances are still shown."
  />
</List>`}>
  <div style={{ maxWidth: 320 }}>
    <List variant="outlined" aria-label="Notices">
      <List.Item
        title="Scheduled maintenance on Saturday between 02:00 and 04:00"
        description="Transfers and card payments are unavailable during the window. Balances are still shown."
      />
      <List.Item
        multiline
        title="Scheduled maintenance on Saturday between 02:00 and 04:00"
        description="Transfers and card payments are unavailable during the window. Balances are still shown."
      />
    </List>
  </div>
</ComponentPreview>

## Accessibility

- Roles: `list` (`ul`, `ol`, or a `div` with `role="list"`) and `listitem`. The role is set explicitly because some screen readers drop list semantics from lists without bullets.
- An interactive row is a real `a` or `button` inside the list item. Its name is the title, the description and any non-interactive trailing text.
- A row never nests controls (see the no-nesting rule above).
- `selected` sets `aria-current="true"` on the row link or button, or on the list item for a static row.
- A disabled link row loses its `href` and gets `aria-disabled="true"`; a disabled button row is natively disabled.
- The automatic chevron and anything you pass as an icon should be decorative (`aria-hidden`). The chevron mirrors in right-to-left layouts.
- `List.Section` renders a heading (`headingLevel`, default 3) and links the list to it with `aria-labelledby`. An `aria-label` on the list takes precedence.

| Key | Action |
| --- | --- |
| `Tab` / `Shift+Tab` | Move between row targets and trailing controls |
| `Enter` | Activate a link or button row |
| `Space` | Activate a button row |

## Mobile

- Rows are at least 44px tall and follow `--tui-row-height`, which is 64px on touch devices regardless of density.
- The whole row is the target for link and button rows, not just the text.
- With a trailing control, the row link and the control are separate targets, so a tap on the Switch never follows the link.
- Long titles truncate instead of pushing the trailing slot off screen; the list does not overflow horizontally at 320px.
