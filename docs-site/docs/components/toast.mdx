# Toast

A notification message that appears temporarily to provide feedback about an action.

## Variants

State is carried by the icon's stroke color, not by a badge, a color band, or the toast's surface. `success` reads `--tui-success`, `warning` reads `--tui-warning`. `info` has no semantic color in v2 — its icon absorbs into the neutral ink (`--tui-ink-3`).

`danger` is the only variant that fills its surface: the whole toast becomes `--tui-danger`, and every piece of text and the close button switch to `--tui-on-danger` for contrast. It is deliberately the odd one out — filling the surface is reserved for the one state serious enough to demand it.

## Progress

Set `showProgress` to draw a 1px rule along the bottom edge that drains from full width to nothing over the toast's `duration`. It is not a colored progress bar — the rule is chrome, drawn in `--tui-rule-strong` (or `--tui-on-danger` inside a `danger` toast), the same restraint the rest of the surface follows: state lives in the icon, not in a filled track.

<ComponentPreview code={`<Toast id="6" variant="success" message="Saved" showProgress duration={4000} />`}>

  </div>
</ComponentPreview>

## Mobile considerations

- Toast surface is an opaque `--tui-sheet` with a `--tui-shadow-overlay` shadow — the toast is genuinely floating above the page, which is why it's one of the few components that uses a shadow at all.
- On `prefers-reduced-motion: reduce`, slide-in animation is replaced with instant fade.
- Toast container should be wrapped in [`<SafeAreaView edges={['top']}>`](../design-tokens/spacing.mdx#touch-targets--safe-area) so notifications clear iOS notch / status bar.

## Usage

`ToastProvider` owns the toast queue and renders the container into a portal; `useToast` gives you the `toast`/`dismiss`/`dismissAll` handles from anywhere inside it.

```jsx
import { ToastProvider, useToast, Button } from 'trust-ui-react';

function SaveButton() {
  const { toast } = useToast();

  return (
    <Button onClick={() => toast({ variant: 'success', message: 'Saved!' })}>
      Save
    </Button>
  );
}

function App() {
  return (
    <ToastProvider position="top-right">
      <SaveButton />
    </ToastProvider>
  );
}
```

### useToast()

Returns `{ toast, dismiss, dismissAll }`.

- `toast(data: Omit<ToastData, 'id'>): string` — queues a toast, returns its generated id.
- `dismiss(id: string): void` — removes one toast.
- `dismissAll(): void` — clears the queue.
