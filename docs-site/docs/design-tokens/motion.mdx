# Motion

trust-ui v2 motion answers user actions. It does not decorate.

## Durations

Three steps — no more:

| Token | Value | Usage |
|---|---|---|
| `--tui-duration-instant` | 80ms | Press/active feedback |
| `--tui-duration-fast` | 140ms | Color, border, background transitions |
| `--tui-duration-base` | 200ms | Everything else that transitions |

## Easing

One curve:

```css
--tui-ease-out: cubic-bezier(0.2, 0, 0, 1);
```

Every transition and animation in the library uses this easing. An earlier version of the library also had a bouncier, overshooting easing curve for hover "lift" effects; that curve is gone in v2 — `--tui-ease-out` is now the only easing token that exists.

## Composite transition token

```css
--tui-transition-color:
  color var(--tui-duration-fast) var(--tui-ease-out),
  background-color var(--tui-duration-fast) var(--tui-ease-out),
  border-color var(--tui-duration-fast) var(--tui-ease-out);
```

Use it instead of writing out the three-property shorthand by hand wherever a component transitions its color, background, and border together on hover/focus/active.

## What moves, and what doesn't

Motion in v2 is a response to something the user did — a hover, a press, a focus change, an item opening or closing. It is never used to introduce content that's simply appearing on screen; there's no library-provided fade-in or slide-in for content that mounts on its own. If nothing happened that a person can point to, nothing should animate.

Hover states also don't use `transform`. A hover effect changes color or border via `--tui-transition-color`, not position or scale — no lift, no shift. This keeps hover cheap (no layout/composite cost beyond a paint) and keeps the interaction model consistent: transform is reserved for cases where an element's position or size is genuinely changing (e.g. an Expander's height), not for signaling hover.

## Reduced motion

Defined once, globally, in `tokens.css` — no per-component opt-in required:

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

Every transition and animation in the library collapses to effectively-instant when the user has this preference set. Components never need their own reduced-motion handling.
